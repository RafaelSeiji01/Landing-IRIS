# Íris — landing page

```
iris-landing/
├── index.html          # estrutura e conteúdo
├── css/style.css       # estilos e animações
├── js/script.js        # animação de entrada no Safari/Firefox
└── assets/             # logo, telas do app e imagem de prévia (og-preview.png)
```

Site estático: na Vercel, basta publicar a pasta (sem build). Para testar local, abra o `index.html` ou rode `npx serve .`.
